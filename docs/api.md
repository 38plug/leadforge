# API Reference

Base URL: `http://localhost:8000`. Interactive docs (Swagger UI) are auto-generated by FastAPI at `/docs`, and the OpenAPI schema at `/openapi.json`.

## Auth

Real, self-contained JWT auth — no external identity provider required.

| Method | Path | Description |
|---|---|---|
| POST | `/api/auth/register` | `{email, password, full_name, workspace_name}` — creates the user, a new workspace, and returns a token. Fails 409 if the email is taken. |
| POST | `/api/auth/login` | `{email, password}` → `{access_token, user, workspace}` |
| GET | `/api/auth/me` | Current user + all workspaces they belong to (requires `Authorization: Bearer <token>`) |

Every other endpoint expects:

```
Authorization: Bearer <access_token>
X-Workspace-Id: <workspace uuid>   (optional — defaults to the caller's first workspace)
```

**Development/test convenience:** if no `Authorization` header is sent, requests fall back to `X-User-Email` (default `demo@leadforge.dev`) resolved against existing rows only — it can select among known dev/test users but can never forge access to a real account, since it never bypasses the workspace-membership check. Run `python -m app.db.seed` to create `demo@leadforge.dev` in a workspace with 35 sample leads for local exploration.

## Leads

| Method | Path | Description |
|---|---|---|
| GET | `/api/leads` | List leads in the current workspace, highest score first. Optional `?status_filter=NEW` |
| POST | `/api/leads/search` | Run the discover → detect website → score pipeline; persists matching leads |
| GET | `/api/leads/{id}` | Full lead detail (company, contacts, socials, website, score) |
| PATCH | `/api/leads/{id}` | Update lead status (`{"status": "CONTACTED"}`) |
| DELETE | `/api/leads/{id}` | Delete a lead |
| POST | `/api/leads/{id}/analyze` | Run AI analysis, returns a validated `AILeadAnalysis` |

`POST /api/leads/search` body:

```json
{
  "filters": {
    "country": "Germany",
    "city": "Berlin",
    "niche": "Dentist",
    "website_status": "NO_WEBSITE",
    "min_rating": 4.0,
    "min_score": 70,
    "require_phone": false,
    "require_email": false,
    "require_instagram": false
  }
}
```

## Campaigns & email templates

| Method | Path | Description |
|---|---|---|
| GET/POST | `/api/campaigns` | List / create a campaign (starts as `DRAFT`) |
| GET | `/api/campaigns/{id}` | Campaign detail |
| PATCH | `/api/campaigns/{id}/status` | Change status (`DRAFT`/`RUNNING`/`PAUSED`/`COMPLETED`) — a `PAUSED` campaign refuses to send |
| GET | `/api/campaigns/{id}/recipients` | List recipients and their delivery status |
| POST | `/api/campaigns/{id}/send` | `{"lead_ids": [...]}` — sends through `CampaignService`, which enforces suppression, per-campaign duplicate prevention, and `daily_send_limit` before ever calling the `EmailProvider` |
| POST | `/api/campaigns/unsubscribe` | **Public, unauthenticated.** `?workspace_id=...&email=...` — adds the address to the suppression list and marks any existing recipient rows unsubscribed |
| GET/POST | `/api/email-templates` | List / create a reusable email template (`{{variable}}` placeholders) |

`POST /api/campaigns/{id}/send` response:

```json
{ "queued": 3, "skipped_suppressed": 1, "skipped_duplicate": 0, "sent": 3 }
```

`queued` counts every recipient row created (including one that hit the daily limit and stayed `PENDING`); `sent` is how many actually went out through the provider this call. Suppressed and previously-contacted leads are never queued.

## Error shape

Provider failures return HTTP 502 with:

```json
{ "code": "PROVIDER_UNAVAILABLE", "message": "AI provider 'openai' is temporarily unavailable", "retryable": true }
```
